# 乐谱图片转 MIDI · 使用教程

把印刷体五线谱**图片**识别成 **MIDI**（以及 MusicXML），可拖进 DAW / 打谱软件继续编辑。

基于开源项目：

| 项目 | 作用 | 地址 |
|------|------|------|
| **HOMR GUI**（主推） | 图形界面，一键出 MIDI | https://github.com/Quackone/homr_gui |
| **HOMR**（识别引擎） | 图片 → MusicXML | https://github.com/liebharc/homr |
| **oemer**（备选 CLI） | 图片 → MusicXML | https://github.com/BreezeWhite/oemer |
| **Audiveris**（备选桌面端） | 功能更全的 OMR 套件 | https://github.com/Audiveris/audiveris |

本机安装位置：`E:\乐谱转MIDI`

---

## 一、30 秒上手（可携带版网页 GUI，推荐）

1. **双击** `启动可携带版.bat`（服务起来后会自动打开浏览器）
2. 若没弹出浏览器，手动打开 **`http://127.0.0.1:8765`**（地址也会印在黑框里）
3. **拖入**乐谱图片（可多选），或点「选择图片」
4. 队列自动识别，完成后点 **「下载 MIDI」** / **「MusicXML」**

> 服务在**独立最小化窗口**里跑；关那个窗口才停服务。再开页面时也可以只跑 `open_gui.ps1`。

同一页还能：
- 看 **模型状态**（已预下载则显示「模型已就绪」）
- 打开 **「命令行」** 面板，复制批量脚本命令

输出在 `输出\` 文件夹。整个 `E:\乐谱转MIDI` 可拷到 U 盘/其它电脑（需同架构 Windows + 自带 `.venv`）。

### 界面状态说明

| 状态 | 含义 |
|------|------|
| 排队中 | 等待 AI |
| AI 识别中 | 处理中，请稍候 |
| 完成 · 可下载 MIDI | 点按钮下载 |
| 失败 | 看报错，换更清晰的图 |

### 乐器识别（自动）

转换时会 OCR 谱面**左侧乐器名**（Horn / Trumpet / Tuba…），写回 MusicXML 的声部名，并映射到 **GM 音色**（圆号 61、小号 57、长号 58、大号 59、定音鼓 48…），MIDI 不再全是 Piano。

- 识别到几个名字就标几轨（多于实际声部数时只取前几条，自上而下对齐）
- 不认识的缩写（Tpt/Tbn/Hn…）也能对上
- 左侧文字糊了会跳过，保持默认 Piano

### 旧版 PyQT 小窗（可选）

双击 `乐谱转MIDI-启动.bat`：Win+Shift+S 截图或拖图，结果写在原图旁。

## 二、命令行批量转换

适合一次处理多张图片：

```bat
转换命令行.bat "E:\乐谱转MIDI\乐谱图片"
```

或把**图片 / 文件夹直接拖到** `转换命令行.bat` 图标上。

也可以手动：

```bat
cd /d E:\乐谱转MIDI
homr_gui\.venv\Scripts\python.exe img2midi.py 乐谱图片 --out-dir "E:\乐谱转MIDI\MIDI输出"
```

输出默认写到 `E:\乐谱转MIDI\MIDI输出\`。

## 四、拍照 / 截图建议（识别率关键）

识别的是**印刷体西方五线谱**，不是简谱、不是手写。

- 尽量**正对**拍，避免倾斜、弯曲、透视变形
- 光线均匀，纸面无阴影、无反光
- 五线谱**完整、清晰**，不要只截一半小节
- 分辨率越高越好；模糊小图容易认错音符时值
- 手机拍照：关掉美颜/滤镜，原图即可
- 复杂总谱可**按行、按系统**分别截，再分别转

出错时可先试：

1. 用 `乐谱转MIDI-CPU兼容.bat`
2. 换更清晰的图
3. 只截取一到两行五线谱先试通

## 五、转换后怎么用 MIDI

1. 用 **MuseScore 4**（免费）打开 `.musicxml`，核对音高、时值，改完再导出 MIDI / PDF / 音频
2. 或把 `.mid` 拖进 DAW（FL Studio、Cubase、Logic、Reaper、Studio One…）
3. 在 DAW 里挂钢琴音源试听，手动微调错音

> AI 识别会有误差，**务必对照原谱校对**，尤其是复杂节奏、多声部、临时升降号。

## 六、常见问题

**模型在哪？**  
CPU 三个 ONNX 已预下载到 `homr_gui\homr\`（约 150MB）。若网页显示「模型缺失」，点「下载/检查模型」或运行：

```bat
homr_gui\.venv\Scripts\python.exe download_models.py
```

支持断点续传，网络差时多跑几次即可。

**提示找不到 python / 启动闪退？**  
先用 `乐谱转MIDI-调试启动.bat`，把窗口里的报错发给我。

**GPU 模式报错？**  
用 `乐谱转MIDI-CPU兼容.bat`。CPU 慢一些，但兼容性最好。

**提示「文件格式不支持 / not supported」？**  
多半是路径里有**中文**（如 `E:\乐谱转MIDI\...`），OpenCV 读不了，HOMR 会误报格式错误。现已自动先拷到临时英文目录再识别，**重启服务或重新跑一遍**即可。

**识别不准怎么办？**

- 提高图片清晰度、裁得更「只含五线谱」
- 多声部、装饰音、复杂节奏本身就是难点
- 生成 MusicXML 后用 MuseScore 人工校对比纯 MIDI 好改

**支持 PDF 吗？**  
当前 GUI 吃图片。PDF 可先用浏览器/预览导出成 PNG，或用 MuPDF/ImageMagick 转图后再转。

**支持简谱 / 手写谱吗？**  
不支持。模型只认印刷体西方五线谱。

## 七、备选方案（进阶）

### 1. oemer（纯命令行）

```bat
pip install oemer
oemer 乐谱.png
```

输出 MusicXML，再用 music21 转 MIDI：

```python
from music21 import converter
score = converter.parse("乐谱.musicxml")
score.write("midi", fp="乐谱.mid")
```

### 2. Audiveris（Java 桌面套件）

适合复杂总谱、要精细校对的场景。需要安装 Java 17+，从 GitHub Releases 下载安装包。  
https://github.com/Audiveris/audiveris

### 3. 在线试用 homr

https://homr.site （无需安装，注意隐私）
